# 🚀 SkillBridge Platform - منصة الخدمات المهنية

منصة ويب متكاملة (Full Stack) تربط بين العملاء ومقدمي الخدمات (كهربائيين، سباكين، نجارين، مبرمجين، إلخ)، تتيح البحث المتقدم الجغرافي، الحجز، التقييم، والدردشة في الوقت الفعلي.

---

## 🛠️ التقنيات المستخدمة

**الواجهة الأمامية (Frontend):**
- React.js + Vite
- React Router DOM (للتنقل)
- Axios (للاتصال بالـ API)
- Socket.io-client (للدردشة والإشعارات)
- Vanilla CSS (بتصميم Glassmorphism حديث)

**الواجهة الخلفية (Backend):**
- Node.js + Express.js
- MongoDB + Mongoose (قاعدة البيانات)
- Socket.io (الاتصال اللحظي)
- JWT (المصادقة وتشفير الجلسات)
- Cloudinary (رفع الصور)

---

## 🏗️ مميزات النظام

1. **نظام مصادقة متكامل**: تسجيل (عميل/مقدم خدمة)، دخول، حماية المسارات (JWT).
2. **محرك بحث جغرافي**: البحث عن أقرب مقدمي الخدمة بناءً على الإحداثيات باستخدام الفهرسة الجغرافية لمونجو دي بي ($geoWithin).
3. **نظام حجز احترافي**: دورة حياة كاملة للحجز (Pending -> Accepted -> In Progress -> Completed/Cancelled).
4. **نظام التقييم والمراجعات**: لا يُسمح بالتقييم إلا بعد إكمال الخدمة لضمان الشفافية.
5. **دردشة وإشعارات لحظية**: تواصل مباشر بين العميل ومقدم الخدمة عند قبول الطلب باستخدام Socket.io.
6. **تصميم عصري (Premium UI)**: واجهة مستخدم مبهرة تدعم الـ Glassmorphism والتوافق مع الهواتف.

## 🚀 طريقة التشغيل خطوة بخطوة

### 1. إعداد الواجهة الخلفية (Backend)
```bash
# الانتقال لمجلد الباك اند
cd backend

# تثبيت الحزم
npm install

# قم بنسخ ملف .env.example وتسميته .env
cp .env.example .env
# تأكد من تعبئة المتغيرات (خاصة MONGODB_URI و CLOUDINARY)

# تشغيل السيرفر (وضع التطوير)
npm run dev
```

### 2. إعداد الواجهة الأمامية (Frontend)
```bash
# افتح نافذة تيرمينال جديدة وانتقل للفرونت اند
cd frontend

# تثبيت الحزم
npm install

# تشغيل التطبيق
npm run dev
```

## 📈 قابلية التوسع (Scalability)

تم بناء المشروع بناءً على بنية **MVC (Model-View-Controller)** وقابل للتوسع بشكل كبير:
- **فصل المهام (Separation of Concerns)**: كل Controller مخصص لوظيفة محددة.
- **تجريد الأخطاء**: `errorMiddleware` مركزي يعالج جميع أخطاء التطبيق ويوحد شكل الاستجابة.
- **استخدام API Features**: كلاس مخصص لمعالجة الـ Pagination والـ Sorting والـ Filtering لتقليل الضغط على قاعدة البيانات.
- **Virtual Fields & Indexes**: تم إضافة فهارس (Indexes) على قواعد البيانات لتسريع عمليات البحث بشكل هائل خاصة البحث الجغرافي.

## 💡 اقتراحات للتطوير المستقبلي (Future Enhancements)

1. **بوابة الدفع الإلكتروني**: دمج Stripe أو PayPal لدفع عربون أو كامل المبلغ عبر المنصة.
2. **تطبيق هاتف (Mobile App)**: تحويل واجهة الـ React إلى React Native لتطبيقي Android و iOS، حيث أن الـ REST API مبنية بالفعل وتدعم ذلك.
3. **مكالمات فيديو/صوتية**: استخدام WebRTC لتمكين العميل من عرض المشكلة لمقدم الخدمة بالكاميرا قبل وصوله.
4. **نظام الولاء والمكافآت**: إعطاء نقاط للعملاء عند كل حجز ناجح يمكن استبدالها بخصومات.
5. **التتبع المباشر**: تتبع موقع مقدم الخدمة على الخريطة أثناء قدومه للعميل (مثل Uber).
